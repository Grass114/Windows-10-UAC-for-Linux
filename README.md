# Windows 10 UAC for Linux 🐧
在 Linux (Debian/Ubuntu/Mint) 系统上完美复刻 **Windows 10 用户账户控制 (UAC)** 体验！
将单调的终端 `sudo` 密码提示，替换为带音效、可拖动、且外观极其逼真的全局图形化 UAC 弹窗。

## ✨ 核心特性
- **像素级复刻**：Win10 标志性蓝条、拖动、悬停变红的关闭按钮。
- **专属音效**：弹窗时自动播放经典的 Windows UAC 提示音。
- **绝对强制**：每次调用 `sudo` 均强制弹出，拒绝 15 分钟免密缓存。
- **极度安全**：
  - 绝不修改 `/etc/pam.d/` 等底层认证文件。
  - 如果弹窗崩溃或取消，自动回退到终端原生密码输入。
  - 自带原生逃生舱，绝不会把你锁在系统门外。
- **一键安装/卸载**：全图形化操作，无终端黑框。

## 🚀 安装方法
1. 克隆或下载本仓库到本地。
2. 确保系统已安装依赖（Linux Mint / Ubuntu 默认已自带）：
   ```bash
   sudo apt install zenity policykit-1
   ```
3. 双击运行 install.sh（或在终端执行 bash install.sh）。
4. 在弹出的系统密码框中授权，并在图形菜单中选择 "🚀 安装到系统"。

💡 使用说明
· 触发 UAC：在终端正常输入 sudo 你的命令（例如 sudo apt update）。
· 强制终端输入：如果你在写脚本，或者觉得弹窗太烦，请使用我们为你准备的逃生通道：
  ```bash
  tsudo apt update
  ```
· 终极逃生舱：如果遇到任何问题，直接使用系统绝对路径：
  ```bash
  /usr/bin/sudo 你的命令
  ```

🗑️ 卸载
双击运行 install.sh，在弹出的菜单中选择 "🗑️ 从系统卸载" 即可瞬间恢复系统原状。

⚠️ 免责声明
本项目通过拦截 /usr/local/bin/sudo 实现。虽然内置了多重保护机制与逃生通道，但修改系统提权流程始终存在一定风险。请确保你了解 Linux 的基本操作后再使用。
